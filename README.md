# fastCaisse

Application web de gestion de caisse.

## Description

**fastCaisse** est une application permettant de gérer efficacement les opérations de caisse :
- Gestion des ventes
- Gestion des produits
- Suivi des transactions
- Gestion des utilisateurs
- Historique des opérations

## Technologies utilisées

- Laravel
- PHP
- MySQL
- Blade / JavaScript
- HTML / CSS
